# ANN Model Work

This folder contains the ANN part of section 4.1.

## Files

```text
models/ann_model.py
  Simple feedforward NARX ANN.

models/lstm_ann_model.py
  Advanced recurrent LSTM ANN.

models/gru_ann_model.py
  Advanced recurrent GRU ANN.

train_ann_assignment.py
  Trains only the simple NARX ANN.

train_lstm_ann_assignment.py
  Trains only the LSTM ANN.

compare_ann_models.py
  Trains the simple NARX, advanced GRU, and advanced LSTM models.

tune_lstm_ann.py
  Tries a few LSTM settings and saves the tuning CSV.

plot_all_ann_results.py
  Makes the final summary plots from the CSV files.

plot_from_saved_results.py
  Makes new plots from saved result CSV files without training again.
```

## Models

We use three ANN models:

```text
Simple ANN:
  NARX feedforward neural network.
  Uses old voltages and old measured angles to predict the next angle.

Advanced ANN:
  GRU recurrent neural network.
  Uses a short sequence of voltage and angle values to predict the next angle.

Advanced ANN:
  LSTM recurrent neural network.
  Uses a short sequence of voltage and angle values to predict the next angle.
```

Both models use only:

```text
u  = applied motor voltage
th = measured disk angle
```

They do not use angular velocity.

## How To Run

From the repository root:

```bash
python 01_system_dynamics_modeling/ANN/compare_ann_models.py
```

This trains/compares the simple and advanced ANN models and creates plots in:

```text
01_system_dynamics_modeling/ANN/results/plots/
```

It also saves the raw results for later plotting in:

```text
01_system_dynamics_modeling/ANN/results/saved_arrays/
```

Important saved files:

```text
ann_scores.csv
  RMSE values for NARX, GRU, and LSTM.

ann_prediction_results.csv
  Measured angle, predicted angle, and prediction error for each ANN model.

ann_simulation_results.csv
  Measured angle, simulated angle, and simulation error for each ANN model.

ann_results_for_plots.npz
  Same result arrays in Python format, useful for making extra plots.
```

The final generated ANN submission files are saved in:

```text
01_system_dynamics_modeling/ANN/results/test_outputs/
```

The current output files are kept in Git so the results are visible to the group.
They can also be regenerated by running the comparison script again.

## Make More Plots Without Training Again

After `compare_ann_models.py` has been run once, use:

```bash
python 01_system_dynamics_modeling/ANN/plot_from_saved_results.py
```

This reads the saved CSV files and makes extra plots in:

```text
01_system_dynamics_modeling/ANN/results/plots/
```
