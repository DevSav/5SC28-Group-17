# 01 System Dynamics Modelling

This folder is for section 4.1 of the assignment: learning models of the unbalanced disk dynamics.

The system input is the applied motor voltage.

The system output is the measured disk angle.

For this modelling part we do not use angular velocity.

## What Is Here

```text
ANN/
  ANN model code, training scripts, comparison scripts, and README.

GP/
  Gaussian Process work from the GP teammate.
```

The ANN and GP results can be compared in the report as two different ways to model the same system.
