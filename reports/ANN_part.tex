\subsection{Method}

The ANN part required at least one simple ANN model and one more
advanced ANN architecture \cite{assignment5sc28}. Therefore, three
models were compared: a feedforward NARX ANN, a GRU, and an LSTM.

The modelling problem is dynamic, so the current angle cannot be
predicted from the current voltage only. Past inputs and past outputs
must also be used. A general nonlinear autoregressive model with
exogenous input (NARX) can be written as

\begin{equation}
\begin{aligned}
\hat{\theta}(k)
=
f\big(&
\theta(k-1),\ldots,\theta(k-n_a),\\
&
u(k-1),\ldots,u(k-n_b)
\big),
\end{aligned}
\label{eq:ann_narx_general}
\end{equation}

where \(n_a\) and \(n_b\) are the output and input memory lengths. In
the simple ANN model, the unknown nonlinear function \(f(\cdot)\) is
approximated by a feedforward neural network. In the implementation,
both memory lengths were set to 15, so the model uses the previous
15 motor-voltage samples and previous 15 measured angle samples.

The NARX network has one hidden layer with 50 neurons and follows the practical-session structure \cite{course5sc28}.
This model is easy to interpret and gives a useful baseline.
In prediction mode, the delayed angles in \eqref{eq:ann_narx_general}
are measured values. In simulation mode, the model must use its own
previous outputs instead of the measured previous angles. In other
words, simulation uses the same model structure as
\eqref{eq:ann_narx_general}, but replaces the measured delayed angles
\(\theta\) by the simulated delayed angles
\(\hat{\theta}_{\mathrm{sim}}\). This is why simulation is a stricter
test than one-step prediction: small errors can be fed back into the
model and affect later samples.

The GRU and LSTM models use the same input-output history, with history
length \(H=15\). The difference is that the recurrent models read the
history as an ordered sequence of voltage-angle pairs instead of one
flattened vector.
A recurrent neural network updates an internal state while reading this
sequence:

\begin{equation}
\begin{aligned}
\mathbf{h}_j
&=
g_{\mathrm{RNN}}(\mathbf{h}_{j-1}, [u(j),\theta(j)]),\\
\hat{\theta}(k)
&=
W_o\mathbf{h}_{k-1}+b_o .
\end{aligned}
\label{eq:ann_recurrent_state}
\end{equation}

The hidden state \(\mathbf{h}_j\) acts as a memory of the previous
samples. This is useful for the unbalanced disk because the measured
angle depends on the recent motion of the disk, not only on the most
recent voltage sample. The difference between GRU and LSTM is the
recurrent layer: GRU is simpler, while LSTM has a more detailed memory
mechanism \cite{course5sc28,cho2014gru,hochreiter1997lstm}.
All models were trained using normalized data, mean squared error loss,
and the Adam optimizer \cite{kingma2014adam}. The known data were split
into 70\% training, 15\% validation, and 15\% test data. The complete
identification dataset contained 35000 measured samples, giving 24500
raw training samples, 5250 validation samples, and 5250 test samples.
Because the ANN inputs use past samples, the supervised training set was
slightly smaller: 24485 training examples for history length 15.

For the ANN models, the main capacity choices were the amount of past
information given to the model and the number of hidden units.
Both choices affect how flexible the neural network can be.
Seven recorded ANN configurations were compared in total: one simple
NARX ANN, one GRU ANN, one final LSTM ANN, and four additional LSTM
tuning runs.

The LSTM tuning runs are shown in Table~\ref{tab:lstm_tuning}.

\centering

History & Hidden size & Prediction RMSE & Simulation RMSE \\
\midrule

\end{table}

The setting with history length 15 and hidden size 60 was selected
because it gave the best LSTM simulation result. This architecture was
then retrained together with the NARX and GRU models for the final ANN
comparison. Since neural-network training is stochastic, the retrained
LSTM result in Table~\ref{tab:ann_results} differs slightly from the
tuning value.

\subsection{ANN Discussion}

The GRU was added to check whether the extra complexity of an LSTM was really needed.
This gives a useful comparison: GRU is slightly better for prediction, but LSTM is better for simulation.
The main limitation is that only a small set of recurrent hyperparameters was tested, so a better setting may still exist.
The ANN simulation task is also sensitive to error accumulation, because
the model recursively uses its own predictions as inputs.
This explains why the simple NARX ANN performs much worse in simulation than in prediction.
Finally, the ANN output used here is a point prediction.
It does not directly indicate the reliability of each prediction.
